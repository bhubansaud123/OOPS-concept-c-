# Mobile Price Analysis Program (C++)

## 📌 Project Overview
This project is a **C++ Object-Oriented Program** that represents a **mobile phone price analysis system**.  
It accepts a company name, mobile model name, and prices from different sellers, then calculates and displays the **minimum price**.

The program demonstrates **core OOP concepts** such as encapsulation, constructors, destructors, and array handling in C++.

---

## 🎯 Objectives
- To practice **Object-Oriented Programming in C++**
- To understand **constructors and destructors**
- To perform **basic price comparison logic**
- To build a simple, exam-oriented C++ project suitable for GitHub

---

## 🧠 Concepts Used

### 🔹 Object-Oriented Programming
- **Encapsulation**  
  Data members (`company name`, `mobile name`, `prices`) are kept private.
- **Constructor**  
  Used to initialize data by taking input at object creation.
- **Destructor**  
  Displays a message when the object is destroyed.
- **Member Functions**  
  Used to calculate and display the minimum price.

### 🔹 C++ Features
- Arrays
- Loops
- Input/Output streams
- String class

---

## 🧩 Program Logic
1. The constructor takes:
   - Company name
   - Mobile model name
   - Prices from three sellers
2. `minprice()` function finds the lowest price.
3. `display()` function prints details.
4. Destructor confirms object destruction.
